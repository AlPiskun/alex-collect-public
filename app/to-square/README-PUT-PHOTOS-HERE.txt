Put the photo(s) you want to square up in THIS folder, then double-click
SquareImages.bat (one level up).

Works with: .jpg .jpeg .png .webp .bmp .tif .gif
Folders inside here are ignored - just the images in this folder are used.

The square versions are written to a "square" subfolder *beside each photo*:
    to-square\my-card.webp            ->  to-square\square\my-card-square.jpg
If you copied the photos in from elsewhere, the square copies appear in
that other folder's own "square" subfolder instead.

Then, on canadianshopper.ca:  Products -> that card -> Edit
    <name>-square.jpg       -> main product image
    <name>-back-square.jpg  -> add as a second image (the back / gallery)
    Inventory               -> what you actually have left
