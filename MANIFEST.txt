Alex Collect 3.00 — public core package

Root:
  LICENSE                         MIT license for the core
  README.md                       installation and project overview
  requirements.txt                Python dependencies
  START Alex Collect.bat          Windows launcher
  install-linux.sh                Linux user install helper
  start-alexcollect.sh            Linux launcher

docs/:
  facebook-feed-settings.md       Facebook workbook settings and template guide
  ebay-quicklist.md               eBay Quick List settings and manual workflow
  TESTING.md                      how to run the checks on Windows before merging

installer/:
  alexcollect.iss                 Inno Setup installer; Python prerequisite
  alexcollect-bundled.iss         Inno Setup installer with private Python
  build-bundled.bat               downloads/verifies the official Python installer
  README.md                       Windows build and install instructions

app/:
  gui.py                          Tkinter control panel
  user_settings.py                shared local preferences for the GUI and tools
  browser_utils.py                installed-browser detection and page launching
  process_utils.py                hides child console windows on Windows
  photo_replace.py                sheet split, blank-slot and replacement naming
  woo_media.py                    upload a photo, set it on the product,
                                   and file it under that product in the
                                   media library
  woo_create.py                   create the batch's products on the website:
                                   drafts first, photos first, read back,
                                   never twice (the CSV stays the record)
  woo_orders.py                   turn a pasted card list into an order
  quote.py                        price a batch for a customer: the cards, the
                                   customer, the discount, the sums, the saved
                                   file, and the order it becomes
  quote_pdf.py                    draw the quote as an A4 PDF - logo, colour,
                                   totals, and a second page when it overruns
  order_pdf.py                    draw an order on the same paper, with a
                                   picture of every card on it
  image_store.py                   move the last batch's card images out of
                                   the way before a new batch writes its own
  doc_images.py                    the cards' pictures: fetch each once, keep
                                   it, draw it in its box (both documents)
  pdf_writer.py                    write the drawn pages as a PDF, with a
                                   link on every card's title
  facebook-feed-settings.example.json
                                  starter values for the Facebook workbook fields
  plugin_manager.py               local ZIP plugin manager
  sale_inputs.py                   generic WooCommerce input readers
  sale_preview.py                  read-only "what sold" preview
  stock_compare.py                 match two stock lists, list what to fix, plan
                                   the write, remember the cards you dismissed
  market_stock.py                  read eBay and Facebook listings with your
                                   session, and name a site's check page
  stock_write.py                   write one stock count onto a website product,
                                   and confirm the site kept it
  cs_listing.py                    build the CanadianShopper import CSV for
                                   website products, and the import defaults
                                   (optional to the pipeline: it has its own copy
                                   of the template for a batch folder with no app)
  sold-everywhere.py              sale checklist workflow
  combine-cs-csvs.py               CSV batch helper
  make-square.py                   photo utility
  pipeline/card_pipeline.py        card listing pipeline
  pipeline/output_history.py       safe CSV/eBay history consolidation
  pipeline/organize_pipeline_outputs.py
                                   preview-first legacy result mover
  pipeline/OUTPUT-FILES.md         pipeline output/retention audit
  pipeline/facebook_merchant_products/facebook_feed.py
  test-*.py                       core tests

Plugins are separate packages. No CanadianShopper plugin implementation,
cookie, credentials, local user settings, or user-generated listing/order data
is included here.
